How to use it

  1. Send a note. When the agent picks it up the note says Working.
  2. Each step appears under the note as it happens.
  3. When it is done, the steps fold into “N steps” under the reply.

Good to know

  • Steps are written in your words, not the agent's: “Finding KMR Waldenburg on your computer”.
  • Want to change course? Write under the note while it works (see Talk while it works).
