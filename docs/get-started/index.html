Get started

Two halves: an agent plugin on your computer and the panel inside Figma. Your agent installs the first one for you.

Set it upLearn by doingWhat the panel says

Set it up

Paste the setup prompt into Claude Code, Codex or Cursor. It installs the agent plugin, starts a small bridge on your computer and checks Node.js 18+ and the Figma MCP.

Setup prompt
Set up Retoucher for me. It lets me leave notes on my Figma layers that you pick up, apply in the Figma file and answer in a panel inside Figma.

1. Install the Retoucher agent plugin for the agent you are:
   - Claude Code: run `claude plugin install retoucher --marketplace alicorak/retoucher`
   - Codex: run `codex plugin marketplace add alicorak/retoucher`, then install it from /plugins and tell me to trust its hooks once
   - Cursor: run `git clone https://github.com/alicorak/retoucher.git ~/.retoucher-plugin` and `mkdir -p ~/.cursor/plugins/local && ln -s ~/.retoucher-plugin ~/.cursor/plugins/local/retoucher`, then tell me to restart Cursor
2. Check that Node.js 18 or newer is installed and that the Figma MCP server is connected. If either is missing, tell me exactly how to fix it.
3. Add the Retoucher Figma plugin. It's waiting for Figma Community review, so it comes with the agent plugin: get the path of its manifest (Claude Code: `retoucher figma-plugin`, or `node <plugin folder>/bridge/cli.mjs figma-plugin\

How to use it

Then add the Figma plugin: while it waits for Figma Community review, your agent gives you a manifest.json to import in the Figma desktop app (Plugins → Development → Import plugin from manifest…). Open it, paste the file's link once, and start watching: /retoucher:watch in Claude Code, “watch my Figma notes” in Codex or Cursor.

Learn by doing

Retoucher Playground is a Figma file with five short chapters. Each exercise is a card next to a design: do what the card says in the panel, and your agent changes the design for real.

Try it

Open Retoucher Playground on Figma Community, duplicate it, and start on page 1 once the panel says Ready.

What the panel says

The status at the top right of the panel tells you where things stand.

PanelMeaning
ReadyAn agent is watching; notes are picked up right away.
Not watchingThe bridge runs, but no agent watches. Notes wait until you start watching.
Not connectedNo agent session is open (opening one starts the bridge), or the agent plugin isn't installed.
Not pairedAnother Figma panel paired first. Ask your agent to run retoucher unpair.
