How to use it

  1. Select the frame.
  2. Open Options → Versions and pick 2, 3 or 4.
  3. Write what you're after (“three moods for the hero”) and send.
  4. The copies appear side by side on the canvas.

Good to know

  • Each version is a real, editable copy, not a picture.
  • Pick the one you like and delete the others, or keep going with a follow-up.
