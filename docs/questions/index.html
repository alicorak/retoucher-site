What should change?

How to use it

  1. A question card appears under the note with the options the agent proposes.
  2. Pick one (or several), or write your own answer, and press Send answer.
  3. For bigger changes the agent can show a plan first: Approve plan or Change with a note.

Good to know

  • Turn on Options → Show a plan first to see the plan before anything changes.
  • Open questions it asks in the note itself: answer in the box under the note.
