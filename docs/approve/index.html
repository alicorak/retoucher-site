How to use it

  1. A permission card appears under the note: what the agent wants to do.
  2. Press Allow once, Always allow or Decline.
  3. The agent continues (or stops) right away.

Good to know

  • Always allow saves the same rule your agent's “don't ask again” would.
  • If the panel is closed or nobody answers within 2 minutes, the agent asks in its own window as usual.
  • In Cursor this covers MCP tools (the Figma edits); shell commands are still approved in Cursor.
