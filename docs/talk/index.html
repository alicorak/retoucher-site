How to use it

  1. Hover a note and press the reply arrow, or write in the box that opens under it.
  2. Send the message. It shows in the note like a chat.
  3. The agent reads it before its next step and adjusts.

Good to know

  • A note that is done stays open for follow-ups: “Not quite right? Say why…”.
  • Use it to correct course instead of starting a new note.
