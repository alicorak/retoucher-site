How to use it

  1. Type @ in the note box.
  2. Keep typing to filter, then pick a variable, text style, effect style, component or library.
  3. The mention is added to the note; send it as usual.

Good to know

  • Library components show up once they are used on the page.
  • Mentions are listed under the note, so you can see what the agent was given.
