How to use it

  1. Open Options → Model and pick one of the models your agent can hand a note to.
  2. Open Options → Skill to pick a skill from the watching session.
  3. Send the note. The chosen model works on it as a helper agent.

Good to know

  • The lists come from the agent that is watching, with their full names.
  • The Model row is hidden when the agent can't pick a model.
