Troubleshooting

The usual cases, and the fix.

Common problems

Most problems are one of these.

SymptomFix
Panel says Not connectedOpen your agent; the plugin starts the bridge when a session starts. Check curl localhost:4747/health.
Panel says Not pairedAnother Figma panel paired first. Ask your agent to run retoucher unpair, then reopen the panel.
Notes stay WaitingThe panel says Not watching: start watching (/retoucher:watch in Claude Code).
Port 4747 is in useYour agent says so when a session starts. Free the port.
The agent can't edit the fileThe Figma MCP isn't connected to your agent, or your Figma seat has no edit access to the file.
Send stays disabledIt needs a note and the file's link: paste the link when the panel asks (once per file).

Still stuck?

Open an issue on GitHub with what the panel says and what your agent printed.
