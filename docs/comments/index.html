How to use it

  1. Open Options → Comments.
  2. Pick Apply to make the changes the threads ask for, or Summarize to get themes, conflicts and a plan you approve first.
  3. The first time, paste a Figma personal access token (scope File comments: read).

Good to know

  • The token is stored on your computer only.
  • Resolved threads are left out unless you ask for them.
