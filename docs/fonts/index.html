How to use it

  1. Write a note that touches type: “Set the headline in KMR Waldenburg”.
  2. The agent looks the font up among the fonts your Figma sees.
  3. The panel changes the text in Figma: family (keeping each weight), size, letter spacing, line height.

Good to know

  • Keep the panel open in that file while the agent works.
  • Undo works for these changes too.
