Your own agent

Retoucher doesn't bring its own AI. The coding agent you already use reads your notes, edits the file through the Figma MCP and answers in the panel.

How to use it

  1. Install the Retoucher agent plugin in the agent you use (see Get started).
  2. Open that agent in any folder. Opening a session starts the bridge, so the panel connects by itself.
  3. Start watching. Claude Code: /retoucher:watch. Codex or Cursor: ask it to “watch my Figma notes”.
  4. Send notes from the panel. The agent picks each one up as it arrives.

Good to know

  • It works on your agent's own account and plan; Retoucher calls no AI service itself.
  • Claude Code uses the retoucher command; Codex and Cursor use the same actions as tools of the retoucher MCP server.
  • Notes live in ~/.retoucher, shared by every agent, so you can switch agents and keep your notes.
