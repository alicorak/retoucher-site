How to use it

  1. Send a note. Its layers get an annotation like “Claude #3 · Waiting”.
  2. The annotation follows the status as the agent works.
  3. When the note is done or deleted, the annotation disappears.

Good to know

  • Turn them off with Options → Show markers on canvas.
  • Other people's annotations are never touched.
