How to use it

  1. Open Options → Build with.
  2. Pick Any library, This file only or a library name.
  3. Send the note.

Good to know

  • The agent builds from the file's components and variables, follows a Figma Spec if there is one, and uses hard-coded values only when nothing fits.
  • Combine it with @mentions to point at one exact component.
