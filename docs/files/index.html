How to use it

  1. Drop files anywhere on the panel, paste them (screenshots too), or press the clip button.
  2. They appear under the note as chips; remove one with its ×.
  3. Write the note and send.

Good to know

  • Up to 8 files per note, 12 MB each. Photos are scaled to 1600 px.
  • Any file type works: images, PDFs, text, design specs.
