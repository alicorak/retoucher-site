Batch

How to use it

  1. Write a note and press Batch (⇧⌘↵) instead of Send.
  2. Repeat for the other notes; they wait in the batch list.
  3. Press Send all. Turn on At the same time if the notes are independent.

Good to know

  • Each note in a batch still gets its own status, steps and Undo.
  • Clear the batch any time before sending.
