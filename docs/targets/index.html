How to use it

  1. Select the first layer and press + (Add selection) in the panel.
  2. Select the next one, on this page or another, and press + again.
  3. Write the note once and send it.

Good to know

  • If you add nothing, the current selection is used.
  • Handy for “make these match”: the agent sees every target side by side.
