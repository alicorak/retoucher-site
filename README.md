# Retoucher site

The launch page for [Retoucher](https://github.com/alicorak/retoucher), served at https://retoucher.alicorak.com from GitHub Pages.

Plain HTML, CSS and JS, no build step. Preview locally with `python3 -m http.server 4810` and open http://localhost:4810. The setup prompt the copy buttons put on the clipboard lives at the top of `main.js` (and in `llms.txt`).
